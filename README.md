# AriaDM

aria2 원격 제어 모바일 앱 (Android/iOS). React Native + Expo 단일 코드베이스로 WebSocket 기반 실시간 다운로드 제어, 다국어(ko/en/zh-Hans/ja), 완료 알림을 제공한다. 서버의 aria2를 리모컨처럼 제어하며 오픈소스 + Freemium으로 공개 배포한다.
