# 홈택스 인터넷 개인사업자 등록 가이드

> **Date**: 2026-08-22
> **Type**: How-to guide
> **목적**: AriaDM 스토어 조직 계정 전환 준비를 위한 개인사업자 등록 — 홈택스 온라인 신청 (세무서 방문 없음)

## 전제 조건

| 항목 | 내용 |
| :--- | :--- |
| 인증 수단 | 공동인증서 또는 금융인증서 (홈택스 로그인 가능한 본인 인증) |
| 사업장 주소 | 필수 — 자택, 사무실, 공유오피스 주소 모두 가능. 사업자 유형에 따라 주택인 경우 세금 이슈 있을 수 있어 주의 |
| 업종 | 홈택스 업종코드 검색으로 선택 (아래 예시 참고) |
| 기한 | 사업 개시일로부터 **20일 이내** 신청 권장 — 늦어도 등록 자체는 가능하나 가산세 대상될 수 있음 |

## 신청 절차

1. **홈택스 로그인** — <https://www.hometax.go.kr> → 공동인증서/금융인증서 로그인
2. **메뉴 이동** — [신청/신고] → [사업자등록 신청·정정·휴폐업] → [개인 사업자등록 신청]
   - 메뉴 명칭은 화면 개편에 따라 다를 수 있음. 검색창에 "사업자등록" 입력으로 메뉴 탐색 가능
3. **신청 유형 선택** — 신규창업 (창업일 = 사업 개시일)
4. **인적사항 확인** — 대표자 정보 자동 조회, 수정 있으면 반영
5. **사업장 정보 입력** — 사업장 주소, 사업장 전화
6. **업종 선택** — 업종코드 검색창에서 키워드 검색 후 선택 (아래 "앱 사업자 업종" 참고)
7. **과세유형 사전심사** — 신규는 사업개시 예정일 기준으로 간이과세 해당 여부 자동 안내
   - 간이과세자 대상: 연매출 8천만원 이하 예상 시 보통 직전연도/예정 매출 기준 판단. 앱 매출이 소액 예상이면 간이과세 검토
8. **제출** — 신청 완료 후 접수증 확인

## 신청 후 처리

1. 관할 세무서 심사 후 **사업자등록증 정보** 확정 — 온라인 신청은 통상 며칠 내 처리 (사업장 실사가 필요한 경우 담당자 연락 올 수 있음)
2. **등록증명서 발급** — 홈택스 [증명서 발급] → 사업자등록증명서 (즉시 발급, 무료)
3. 사업자번호 수령 후 아래 "다음 단계" 진행

## 앱 사업자 업종 (AriaDM 기준 예시)

| 구분 | 예시 |
| :--- | :--- |
| 업태 | 정보통신업 |
| 종목 | 소프트웨어 개발·공급업 (업종코드는 홈택스 검색창에서 "소프트웨어 개발" 검색하여 선택 — 코드 번호는 개편 시 변동되므로 화면 기준) |

> ⚠️ 정확한 업종코드와 과세유형 판단은 화면 안내 및 필요시 세무사 확인 권장. 본 문서는 절차 안내이며 세무 자문이 아님.

## 다음 단계 (사업자등록 후 — 스토어 조직 전환)

1. **D-U-N-S 번호 발급** — <https://www.dnb.com> 무료 자가 신청 (한국은 D&B Korea 처리, 영업일 기준 수일~수주)
2. **Google Play 조직 전환** — Play Console에서 조직 프로필로 전환 또는 신규 조직 계정 + 기존 앱 이전([앱 이전 가이드](https://support.google.com/googleplay/android-developer/answer/9233537))
3. **Apple Developer Organization** — [Enrollment](https://developer.apple.com/programs/enroll/)에서 법인/개인사업자 등록 (D-U-N-S 필수). 기존 Individual 앱 이관 가능
4. 통신판매업신고 — 앱 내 유료 결제가 아닌 웹 판매 시에만 필요 (IAP만 쓰면 불필요)

## 주의사항

- 메뉴 명칭·화면은 2026-08 기준 — 실제 화면과 다르면 국세청 상담센터 **126** 또는 [국세청 사업자등록 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2444&cntntsId=7777) 확인
- 홈택스 공식 이용안내: <https://hometax.go.kr/html/pp/info/newBIzMan04.html>
- 개인사업자는 종합소득세 신고 의무 발생 (다음 해 5월) — 매출 발생 시 기장(간편장부/복식부기) 준비
- 단순 등록 비용은 무료. 세무사 대리 신청 시 대리 비용 발생하나 본 가이드는 본인 직접 인터넷 신청 기준
